# ЖК «Монблан»: анализ продаж

Игорь Батов · вариант 1 · проект по визуализации

[Открыть интерактивный дашборд](https://batovigor2003-maker.github.io/montblanc-sales-dashboard/)

Данные за март–сентябрь 2026 года: 367 квартир, 248 квартир с датой сделки

## Что показывает дашборд

- Недельные продажи, WoW и среднее за четыре полные недели
- Выручку, сделки со скидкой и без, недельные изменения количества и сумм
- Продажи и остаток по комнатности и корпусам
- Матрицу «корпус × комнатность» и группы для первичного разбора
- Продажи по этажам и видам из окна
- Ежемесячный рейтинг менеджеров по числу сделок и топ-3 для премии
- Детализацию отдельных квартир с ценой, стоимостью, этажом и видом

Фильтры характеристик меняют выбранный фонд. Неделя и менеджер уточняют показатели сделок, сохраняя знаменатель доли продаж. Рейтинг премии всегда считается по всем сделкам ЖК за выбранный месяц

Последняя неделя содержит только 28–30 сентября и исключена из сравнения с полной неделей. При нулевой базе WoW в процентах не рассчитывается. Равенство на границе топ-3 помечено отдельно

Выручка не равна прибыли. Скидки не доказывают убыток или влияние на покупку. Причины различий между группами по этой выгрузке не установлены
